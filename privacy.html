Privacy policy: Java Hub Autopost

Last updated: 25 November 2026

Java Hub Autopost is a personal tool used only by the owner of the Java Hub channel to upload and schedule Java Hub's own videos on the owner's own YouTube channel and Instagram account.

What it accesses

  • YouTube (via Google sign-in): permission to upload videos to, and manage the publishing status of videos on, the owner's channel.
  • Instagram (via Facebook Login): permission to publish Reels to the owner's Instagram professional account.

What it stores

Sign-in tokens are stored only on the owner's computer, in the macOS Keychain. Post IDs and links are stored in the owner's local files. No data is sold, shared with third parties, or used for advertising, and no data about other people is collected.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions (Google) and in Facebook/Instagram settings under Apps and websites. Deleting the Keychain entries named "javahub-autopost" removes the stored tokens.

Contact

Questions: send a direct message to @java._hub on Instagram.
